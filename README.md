# ぶどうをラブラブにする魔法

一張手工收藏卡的數位延伸。以 iPhone 15 Pro 直式觀看為主要設計情境。

## 視覺與互動

「夜藍手稿」：深夜藍背景、象牙文字、細銀框、兩行各自置中的纖細日文明朝體標題（Noto Serif JP，字重 267）。原創卡牌完整呈現，卡牌周圍帶有清楚而柔和的銀藍與玫瑰色光暈，以 9 秒往返呼吸；標題後方保留淡粉光暈。「ラブラブ」以淡玫瑰粉為底，以獨立 inline-block 顯示，與封面原有的銀色掃光同步循環；兩者皆為 1.8 秒、延遲 .45 秒、相同緩動曲線。播放時裝飾動畫暫停；偏好減少動態效果的裝置呈現靜態光暈與金屬粉色。收藏編號 001 / 001。

主動點擊封面或 touch to begin 後，在頁面內觀看影片。支援暫停、進度跳轉、聲音開關、返回封面；切換分頁時自動暫停。播畢淡回封面，提示改為「もう一度」。

小於 570px 高的視窗保留自然捲動，避免內容擠壓。允許使用者縮放。標題字型只包含用到的字元並由本站託管；授權見 assets/fonts/NotoSerifJP-OFL.txt 與 assets/fonts/OFL.txt。沒有分析追蹤、第三方播放器或外部字型請求。

## 目前素材

- 封面：使用者原創 FRONT.png 的既有 JPG 匯出版，815 × 1110，保留原比例與色彩。
- 影片：縮時.mp4，800 × 1088、H.264、30fps，約 29.93 秒，無音軌。
- 目前影片並非 9:16，使用 contain 保留所有畫面。容器已重整為 faststart，媒體內容沒有重新編碼。

## 替換正式影片

1. 以正式影片覆蓋 assets/video.mp4；建議 1080 × 1920、H.264／AAC、MP4 faststart。
2. 將 index.html 影片路徑的 ?v=3 改成下一個版本，避免手機沿用舊快取。
3. 封面可獨立覆蓋 assets/cover.jpg。若比例改變，再調整 style.css 的 .artwork 與 .artwork-wrap。
4. 提交到 main，等 GitHub Pages 發布完成。網頁網址不需更換，QR Code 持續指向同一頁。

進度與時間由影片實際長度讀取。正式影片加入音軌後，使用者主動播放即可帶聲音播放。

## 本機預覽

在網站根目錄執行 python3 -m http.server 4173 可檢查版面。若要測試影片任意跳轉，預覽伺服器須支援 HTTP Range；GitHub Pages 正式環境另行驗證。

## 驗證範圍

本次在 Chrome 的 393 × 852 與 393 × 680 視窗檢查版面與主要播放流程。iPhone Safari 的實機 safe area、系統中斷與聲音，仍需在送禮前以手機掃描測試；目前沒有音軌，不能驗證有聲播放。
